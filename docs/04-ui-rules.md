# Batch UI Rules

## Product feel

Batch must feel like a live deal-clearing app.

It should feel closer to:

- Circle
- Linear
- Cash App
- Flexport shipment views
- serious fintech dashboards

It should not feel like:

- Shopify
- Amazon
- Jumia
- Kickstarter
- crypto launchpad

## Design language

- white background
- near-black text
- muted gray borders
- one restrained accent color
- generous spacing
- compact cards
- light typography
- clean progress indicators
- no noisy gradients
- no hype illustrations

## Core screens

### Buyer home

Must show:

- active commitments
- batches closing soon
- batches clearing today
- delivery updates
- escrow protected amount
- refund alerts

### Live batches

Must show deal cards, not product cards.

Each card includes:

- title
- supplier
- batch type
- current price
- normal market price
- savings
- progress
- minimum needed
- deadline
- delivery estimate
- escrow status
- risk level
- commit CTA

### Batch detail

Must feel like a deal room.

Sections:

- status header
- progress to clearing
- price tiers
- deadline clock
- supplier summary
- escrow plan
- milestone timeline
- delivery plan
- refund rules
- buyer activity
- commit panel

### Commit flow

Short and clear:

1. Choose quantity
2. Select delivery method
3. Review escrow and refund rules
4. Confirm commitment
5. Receive commitment receipt

### Supplier portal

Must show:

- batch creation wizard
- commitment progress
- milestone checklist
- proof upload
- payout timeline
- allocation summary

### Operator console

Must show:

- stuck batches
- overdue milestones
- risky suppliers
- pending payouts
- refund queue
- open disputes
- payment event failures
- audit logs

## Core CTA language

Use:

- Commit
- Join batch
- View batch
- Track allocation
- Confirm delivery
- Request refund
- Transfer slot
- Upload proof
- Approve release

Avoid:

- Add to cart
- Buy now
- Shop now
- Mint
- Stake
- Ape in

## Motion rules

Use motion only where it improves clarity:

- progress bar movement
- state transitions
- timeline updates
- drawer open/close
- success confirmation

Do not use decorative motion that slows the app.

## SVG and illustration rules

Use simple SVG illustrations for:

- batch clearing
- escrow stages
- delivery allocation
- refunds
- Arc/Circle settlement path

Style:

- line-based
- minimal
- monochrome with one accent
- readable at mobile size

## Mobile-first rule

Every core flow must work on a phone before desktop polish.

The buyer app is the priority.
