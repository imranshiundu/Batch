# Batch Brand and Visual System

## Brand position

Batch should look serious, useful, and calm.

It is a money coordination app. It should not look like a crypto launch page.

## Voice

Short sentences. Clear logic. No hype.

Use:

- buy together
- pay only when the deal clears
- commit funds
- clear the batch
- receive your allocation
- refund automatically

Avoid:

- revolutionize
- ecosystem
- web3 native
- next generation
- democratize everything
- AI-powered marketplace

## Color direction

Base:

- white
- near black
- muted gray

Accent:

- one deep green, blue, or graphite accent

Status colors should be functional:

- clear
- caution
- blocked
- delayed
- refunded

## Typography

- clean sans-serif
- light font weights
- strong hierarchy
- compact dashboard labels
- generous line height on marketing copy

## Illustration direction

Use line-based SVGs.

Illustrations needed:

1. Batch clearing diagram
2. Escrow milestone release diagram
3. Buyer allocation diagram
4. Refund path diagram
5. Arc/Circle settlement path diagram
6. Supplier proof upload diagram
7. Hub pickup diagram

## Animation direction

Subtle animations only:

- progress to clearing
- batch status timeline
- escrow release steps
- delivery tracking
- commitment success

No decorative heavy animation in core app flows.

## App empty states

Empty states should teach the product.

Example:

No active commitments yet.

Join a batch to lock in a group price. If the deal clears, your allocation is reserved. If it fails, your funds return.

## Icon language

Use simple icons for:

- commitment
- escrow
- clearing
- supplier
- delivery
- refund
- dispute
- payout
- proof
- allocation
